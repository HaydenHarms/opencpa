# Plan: FAR simulations to 50

Hayden's direction (2026-10-02): after the MCQ gaps close, run simulation batches until FAR has 50 simulations. Three exist (`docs/reviews/far-tbs-01.md`), so this plan adds 47 in eight batches, `far-tbs-02` to `far-tbs-09`. Each batch is one area, so batches can run in parallel without sharing a topic.

Every simulation follows the pipeline in `docs/content-pipeline.md`: the MCQ quality bar plus its **Simulations** section. That means at least two source-style exhibits with data to reject, no cross-task giveaways, 6–10 points, harder than any MCQ on the topic, a stated rounding rule, and one key line per account. Every number is computed in code. The blind verifier runs on every task. The review gate covers every simulation in full.

**Target mix for all 50:** Area I 18, Area II 17, Area III 15 (36% / 34% / 30%). At least a third should be Analysis, using the blueprint's Analysis tasks. Use `select` tasks for classification choices instead of prompts that leak the classification. Research tasks stay out until cited paragraphs can be checked against the Codification.

Ids are `far-tbs-<slug>-NNNN`. Never reuse an id that git history has used. These are taken: `bank-reconciliation-0001`/`-0002`, `income-tax-provision-0001`/`-0002`, `lessee-accounting-0001`, `lessee-finance-0001`.
